Google Translate: Copy Button

Head to Google Translate

How to Locate the Copy Button

After entering text to translate, the user can locate the Copy button in the bottom-right corner of the translated text area. It is the first button in the row.

TRIGGERS

  • Hover ON
  • Hover OFF
  • Mouse DOWN
  • Mouse UP

RULES

Hover ON

  • Cursor changes to finger
  • A light gray circular background appears behind the Copy icon
  • After a short delay, a "Copy translation" label appears below the Copy icon

Hover OFF

  • Cursor changes back to default
  • The light gray circular background disappears
  • The "Copy translation" label disappears

Mouse Down

  • The circular background changes from light gray to dark gray

Mouse Up

  • The translated text is copied to the clipboard
  • Circular background returns to light gray
  • "Copy translation" label disappears
  • A "Translation copied" confirmation message slides up from the bottom-left of the screen, then slides down after a short delay

FEEDBACK

Hover ON

  • Cursor changes to finger
  • Copy icon is highlighted with a light gray circular background
  • After a short delay, a "Copy translation" label with a dark gray background and white text appears below the Copy icon

Hover OFF

  • Cursor changes to default
  • The light gray circular background disappears immediately
  • "Copy translation" label disappears after a short delay

Mouse Down

  • The circular background changes from light gray to dark gray with an expanding effect

Mouse Up

  • Circular background returns to light gray
  • "Copy translation" label disappears
  • A "Translation copied" confirmation message with a black background and white text slides up from the bottom-left of the screen, then slides down after a short delay

LOOPS & MODES

LOOPS

  • NONE

MODES

  • A "Translation copied" confirmation message appears at the bottom-left of the screen after the Copy button is activated
