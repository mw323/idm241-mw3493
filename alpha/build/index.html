Alpha Build: Copy Button

This is the translated text.
Copy translation

TRIGGERS

  • Hover ON
  • Hover OFF
  • Click

RULES

Hover ON

  • Cursor changes to finger
  • The button background changes from transparent to light gray
  • The copy icon slightly scales up
  • Label "Copy translation" fades in and moves slightly upward

Hover OFF

  • Cursor changes back to default
  • Button background returns to transparent
  • Copy icon returns to its original size
  • Label "Copy translation" fades out and moves slightly downward

Click

  • When pressed, the button becomes smaller and the background turns darker
  • The button then returns to its original size with a light green background and green border
  • Copy icon disappears and an animated check icon appears
  • Label changes from "Copy translation" to "Translation copied" and turns green
  • Translation text is copied to the clipboard
  • After a short delay, the button returns to its default appearance
