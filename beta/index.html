RULES

Star Save Button

Hover ON

  • Cursor changes to finger
  • A light gray circular background fades in behind the Save button
  • The star icon slightly increases in size
  • The "Save translation" label fades in and moves upward

Hover OFF

  • Cursor changes back to default
  • The light gray circular background fades out
  • The star icon returns to its default size
  • The label fades out and moves downward

Click ON

  • The circular background fades to a darker gray while the button is pressed
  • The unfilled gray star fades out, while the filled orange star fades in with a brief pop animation
  • The label text fades from "Save translation" to "Translation saved"
  • The translation changes to a saved state
  • The saved translation is stored in the database

Click OFF

  • The circular background fades to a darker gray while the button is pressed
  • The filled orange star fades out, while the unfilled gray star fades in
  • The label text fades back from "Translation saved" to "Save translation"
  • The translation changes to an unsaved state
  • The saved translation is removed from the database

Listen Button

Hover ON

  • Cursor changes to finger
  • A light gray circular background fades in behind the Listen button
  • The speaker icon increases in size
  • The "Listen" label fades in and moves upward

Hover OFF

  • Cursor changes back to default
  • The light gray circular background fades out
  • The speaker icon returns to its default size
  • The "Listen" label fades out and moves downward

Click ON

  • The circular background fades to a darker gray while the button is pressed
  • The speaker icon fades out and is replaced by three animated audio bars
  • The "Listen" label fades out and moves downward
  • The translation audio begins playing
  • The audio bars continuously move up and down while the audio is playing

Click OFF

  • The circular background fades to a darker gray while the button is pressed
  • The animated audio bars stop and disappear, and the speaker icon fades back in
  • The "Listen" label fades back in and moves upward while the cursor remains over the button
  • The translation audio stops playing
